# Windows 锁屏登录与画面恢复

分支：`feat/remote-desktop-v1`。在独立 worktree 开发；本机安装版、主工作区和
其他会话的代码均未修改。编译使用 8 jobs；同时运行的前端构建限制在 2 个 CPU，
合计不超过 10。

## 本轮实现

- 独立窗口增加 Ctrl+Alt+Delete。仅在启用操作后可用，服务端入口也检查窗口所属
  账号和当前控制状态；先停止本地输入并禁用当前远端输入，再调用已有认证连接
  上的 `DesktopInputEvent::SecureAttention`。复用现有 Windows 服务 SendSAS，
  不使用普通组合键模拟，不新增鉴权体系。
- 桌面媒体的关闭、超时、传输中断、MediaUnavailable、StaleGeneration 可自动
  重开。最多连续重试 6 次，间隔 250/500/1000/2000/2000/2000 毫秒；实际连接
  操作本身的超时另计。首帧之后稳定至少 5 秒才清零连续失败计数。
- Busy、WrongOwner、Unsupported、InvalidRequest、NotFound、格式错误和认证
  失败不自动重试。重试耗尽显示失败，保留手动重新连接。
- 旧媒体失败后尝试关闭旧会话（最多等待 2 秒），再重开，减少旧占用尚未清除时
  的 Busy 竞争。此操作不主动断开现有普通设备连接。
- 恢复过程中显示“正在恢复画面”；新会话恢复为仅查看。上一代待处理的操作开关
  和 SAS 不重放，密码、按键和点击不缓存重放。窗口关闭、账号变化可取消恢复。

## 90 实机验收

机器：Windows Server 2022 / RTX 4090，Administrator 会话 2，1920×1080 单屏。
沿用用户明确提供的锁屏测试授权。本轮未重启、注销或切换用户。

1. 在原安装服务运行时确认普通设备连接、交互用户上下文和截图通道可用；本地
   DPAPI 文件可解密。密码只在进程内读取，经匿名 stdin 传给原生输入测试驱动，
   没有进入命令参数、远端任务 stdin、测试输出或仓库。
2. 对会话 2 发起一次 LockWorkStation。截图确认真实锁屏，并显示需要
   Ctrl+Alt+Delete。通过原安装服务的既有 SAS 接口发起一次请求，截图确认进入
   Administrator 空密码输入框。
3. 在临时目录启动本分支的 SYSTEM Default/Winlogon 媒体 helper 和临时 Executor。
   使用既有设备账号、密码和配置，设定 7 分钟测试进程上限与 10 分钟服务恢复
   计划任务；没有覆盖安装文件或服务配置。
4. 用 `remote_desktop_input_check` 经真实认证连接打开 Winlogon 媒体。H.264
   传输、D3D11 解码和显示首帧成功，关闭会话成功。
5. 再次打开 Winlogon 媒体，启用原生输入，输入已授权凭据并提交一次登录。
   登录引发旧媒体代次结束；截图确认回到原有用户桌面，没有重试登录。
6. 重新打开 Default 桌面媒体，首帧显示及关闭成功。输入恢复文件的非零标记
   数为 0；独立观察窗口确认 Ctrl 和鼠标左键均未保持按下。
7. 原安装服务恢复为 Running，临时进程数为 0。全部 5 个测试计划任务和临时
   目录已删除；90 保持已登录。测试前后旧截图、命令、查询通道均可用。
