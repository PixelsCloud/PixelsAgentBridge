# Windows 正式窗口 → Linux Xorg GDM 密码登录

日期：2026-10-17。Linux 实现提交 `0824412`。
[机器记录](remote-desktop-linux-system-login-2026-10-17.json)包含产物哈希、logind
状态、窗口恢复状态、实际显示采样及服务恢复信息。

## 本次通过的范围

在同一个 Windows 正式独立远程桌面窗口内，经项目现有网络连接，完成：

1. 查看 Linux VM 的原 hy/Wayland 会话 13，实际采集画面已显示。
2. 测试控制器锁定原会话，创建 Xorg GDM 登录界面。logind 确认原会话
   `LockedHint=yes`、非活动，GDM c17/UID 128 活动。
3. 窗口自动恢复为 `x11:0:Virtual1` 的登录界面，无手动重开或点击重连。
   用户列表和密码输入框均从原生观看窗口实际画面确认。
4. 在窗口启用操作，使用其原生输入表面点击 hy 用户，再输入已有私有测试
   资料中的系统密码并按 Enter。密码仅在内存中使用，提交一次，不进入命令
   参数、源码、日志或验收文件。
5. 在执行任何恢复命令前，logind 确认原会话 13 活动且 `LockedHint=no`，
   受监督 helper 切回 UID 1000。窗口自动恢复为 `gnome:Virtual-1`，
   `frame_ready=true`，并重置为“仅查看”。

对实际原生窗口的登录前后截图，在排除凭据区域的应用下半部分取 4,692 个
采样点，全部 RGB 差值不超过 15，确认实际桌面画面恢复；没有仅用“已连接”
状态证明显示成功。含有安装版设备凭据的原始截图未纳入 Git。

控制台独立恢复计时器的 `LastTriggerUSec` 为空；密码登录验证发生在人工执行
清理恢复之前，排除了自动解锁恢复脚本造成成功假象。

## 构建和测试环境

Linux Executor Release 以 Cargo 4 jobs、嵌套原生构建 1 job 构建通过，SHA-256：
`802ab09cfa6c938fe5b2a09abe4f1294431c02edf5234b971e222551e150ca64`。
Desktop 复用已验证的 `30dea5f6…` 产物。Windows 使用隔离 profile 与已有正式
原生观看实现，具体 Desktop/MCP 哈希在机器记录中，不替换本机安装版。

Linux 通过 `/run/systemd/system` 临时覆盖启动隔离目录中的新 Executor，保留
原设备身份和服务配置；设置独立回滚计时器。监督进程在单独的临时系统服务中
运行，退出时 systemd 删除其运行目录。没有覆盖 `/opt` 中的安装程序。

首次打开窗口的测试调用发生在 WebView 的 Tauri 初始化之前，返回 TypeError，
未产生窗口；检查实际 WebView 初始化完成后再次打开成功。之后从普通桌面到
登录界面再返回，均使用该次打开的窗口，没有手动调用重连。
