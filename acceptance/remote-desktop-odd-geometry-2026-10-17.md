# 奇数分辨率：完整画面与边缘输入

日期：2026-10-17。基线 `9e3b49d`；本轮修改的源码哈希、失败对照、产物和实测
数据见[机器记录](remote-desktop-odd-geometry-2026-10-17.json)。

## 问题与实现

Linux VM 的实际分辨率为 1297×752。旧采集端要求宽高均为偶数，导致正式窗口
启动时遇到 EOF。现在协议继续使用实际可见尺寸；H.264/NV12 编码尺寸仅向右、
向下补齐到偶数，显示裁掉补齐区域后再旋转，输入仍映射到真实屏幕。

软件 BGRA→YUV 在原转换循环中复制最后一行/列，不增加整帧 BGRA 副本；保留
偶数尺寸的原循环。Windows NVENC 对偶数纹理继续直接编码，仅奇数纹理增加
GPU 内的边缘补齐，不进行 CPU 回读。Linux 采集接受奇数尺寸；三平台解码和
显示端使用补齐后的纹理尺寸、实际可见的画面比例。

第一次实测仍失败：Windows 显示最右边的 1 像素白边丢失。独立解码源数据的
最后可见列和补齐列亮度均为 235，证明编码保留了边缘。使用生产 GPU presenter
直接显示生成的 NV12 数据，四组尺寸×四种旋转中，偶数的 4 组通过，奇数的
12 组均丢掉相应边缘。当前驱动在 NV12 裁剪时将边界向偶数对齐。

修复只影响奇数尺寸：先在 GPU 将完整编码表面转为 RGB，再精确裁剪和旋转；
偶数尺寸仍使用原单次 video processor 路径。没有 CPU 像素回读。

## 验收结果

- Windows、Linux、Mac 完整 Desktop 编译通过。媒体单测分别为 14、15、14 项，
  包含奇数边缘、stride 填充、不完整最后行、尺寸上限及 H.264 往返检查。
- Windows 生成 NV12 的 16 组显示测试修复后全部通过。四边和右下角为白，
  内侧相邻像素保持背景色，未把补齐列拉伸到画面中。失败对照保留。
- Windows NVENC 实际编码 1298×754、1297×754、1298×753、1297×753 各三帧。
  检查明确禁止软件回退；独立 FFmpeg 解码后，边缘和补齐角均保留，内侧像素
  正常。这里只证明硬件编码几何路径，不是新性能基准。
- Windows 正式独立窗口通过已有认证连接 Linux VM。1297×752 按 1:1 显示，
  四边、角点和内侧像素检查通过。真实网络点击结果如下：

| 目标像素 | 远端窗口实际坐标 | 按下/抬起 |
| --- | --- | --- |
| (1296,376) | (1296.0,376.0) | 各 1 次 |
| (648,751) | (647.98828125,751.0) | 各 1 次 |
| (1296,751) | (1296.0,751.0) | 各 1 次 |

最大坐标误差 0.01171875 像素，结束时无按住状态。没有调整虚拟机分辨率。

- Mac AppKit 宿主实测默认解码和强制软件解码；原偶数 fixture 及新 1297×753
  fixture 均呈现八帧，并通过隐藏时不确认显示、静帧恢复和取消待显示帧检查。
  Metal shader 已实际运行。此项不采集用户屏幕、不发送系统输入、不改 TCC；
  固定已授权 App 和安装版均未替换。它不等价于逐像素验证 Mac 奇数边缘。
- 两轮 Linux 临时部署均恢复原服务、配置、unit 和用户会话 191；最终原服务
  PID 44895。自有媒体进程、虚拟输入设备、运行目录及本地隔离 profile 已清理。

编译总并发没有超过 10：Windows/Linux Cargo 8 jobs，Mac 4 jobs；原生测试编译
为单核，和 Mac 编译同时运行时总预算为 5。没有更新本机安装版。

## 复现工具与范围

`experiments/remote-desktop/build_windows_odd_geometry.py` 串行构建两个生成图案
的原生探针。presenter 探针需要可见桌面；encoder 探针在其独立输出目录运行，
随后使用 `verify_windows_odd_encoder.py` 检查生成码流。Linux 的全屏测试图案为
`linux_edge_fixture.py`；Mac 宿主检查为 `macos_host_check` example。

Linux/Mac 奇数显示边缘的逐像素实测、物理多屏变化及 Mac 奇数源采集仍待补齐。
Mac 硬件采集编码仍要求偶数源尺寸；本轮不能声称三平台任意分辨率全部完成。
此修复没有重新测量动态 FPS，不替代原注销登录回归、弱网、长稳、九种组合或
安装发布验收。W1–W8 保持未完成。
