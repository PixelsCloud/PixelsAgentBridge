# Desktop 账号页与连接入口验收（2026-10-21）

基于 `feat/remote-desktop-v1` 的 `6af2e0451cc577f1f9996e7e94bf23d4ed793701`，下列源代码改动尚未打包发布，未替换本机安装的应用。

## 账号页

- 顶部为“我的”和“打开后台”，个人信息卡集中显示头像、账号和可复制的账号 ID。
- 本机账号关联、远程设备列表同步分别成卡；常规窗口并排，窄窗口上下排列。
- GitHub 绑定与退出账号位于底部；关联、同步、绑定和退出逻辑沿用现有命令。
- 后台按钮调用原生 `open_account_console`，由原生端读取当前进程实际生效的控制服务地址（包括私有内置默认值、用户覆盖和 `--config`）。不读取可能为空的设置输入框作为跳转依据，也不使用尚未重启生效的配置。
- 复用账号 API 的 `account_origin` 规则，将 `wss://customer.invalid:8443/control` 转为 `https://customer.invalid:8443/`，保留自定义主机与端口，移除路径和查询参数。服务端 Web 控制台由该 origin 提供。
- 不向浏览器 URL 注入客户端令牌；浏览器沿用自身登录状态，需要时正常登录。配置缺失或无法解析时显示失败提示，不回退官网。IPC 不接收前端 URL，且只允许主窗口调用。

## 设备菜单连接反馈

- 远程桌面、远程终端、远程终端（System）、连接共用连接进度与失败对话框。
- 缺少密码或密码错误时可直接输入新密码，重试后继续原入口和终端模式。
- 离线、设备不存在、无权限、超时、控制服务暂不可用均显示对应提示；原有服务端限流错误仍按实际返回展示，没有新增使用限制。
- 不因卡片上的旧“已连接”状态跳过连接检查；不依赖在线状态提前阻止用户连接。
- 关闭等待对话框后，过期请求不能打开窗口或覆盖较新的连接状态。窗口启动失败时保留已经成功建立的连接。
