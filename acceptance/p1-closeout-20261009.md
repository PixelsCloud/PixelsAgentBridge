# P1 用户系统收尾与一账号多设备验收

日期：2026-10-09。延续 [个人中心验收](p1-personal-center-20261009.md)，替代其中尚未完成的 GUI 和 Release 状态。

## 本次产品规则与实现

- 一个账号可以拥有多台设备，一台设备当前归属一个账号。同账号登录 Windows、Mac 时，两台同时出现在「我的设备」。
- 登录其他账号自动更换当前这台设备的归属，无需换绑确认，不影响原账号的其他设备。Server 对已有客户端的 `automatic` 请求执行相同规则。
- 重复同步幂等；退出、离线、应用重启不删除关联。关联仍须有效登录会话、本机 Executor 签名证明和关联版本检查，不赋予额外设备控制权限。
- Web 解除后，解除之前的登录会话不能通过轮询立即重新关联。解除之后新建的登录会话自动重新关联，也保留本机主动关联入口。
- 无数据库重建、无设备重新注册、无账号清空。`device_accounts` 原结构即支持一对多，不需要迁移。
- Desktop 移除换绑确认框，三语言文案改为自动同步/重新登录关联。源码和前端编译验证通过；本次未重新安装 Desktop，已安装客户端已直接获得新的自动关联行为。
