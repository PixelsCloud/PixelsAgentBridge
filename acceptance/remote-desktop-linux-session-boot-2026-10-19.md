# Linux Wayland 注销与真实重启登录

日期：2026-10-19；Windows 操作端源码基线 `a690c81`。本轮在 Ubuntu 22.04 虚拟机上使用隔离候选，
沿用此前 Linux 被控端媒体产物；不将它描述为重新构建了同一提交的三平台发布包。
具体产物哈希及恢复采样见[结构化记录](remote-desktop-linux-session-boot-2026-10-19.json)。

## 实测结果

同一个 Windows 正式远程桌面窗口经现有可靠传输查看 Linux；H.264、D3D11 硬解，协商 15 FPS。
这里的 15 FPS 是配置值，本轮没有重新测量动态画面实际显示帧率。

| 场景 | 系统侧确认 | 原窗口恢复 |
| --- | --- | --- |
| 注销用户 | Wayland 用户 session 2 退出，进入 GDM Wayland greeter c2 | 16.37 秒恢复登录画面，只查看 |
| 注销后登录 | 选择 hy，核对空密码框后通过原生窗口提交一次密码，进入用户 session 277 | 7.64 秒恢复用户桌面，只查看 |
| 真实重启 | boot ID 改变，开机未登录，GDM greeter c1；候选 Executor 与媒体 supervisor 已自动启动 | 34.11 秒恢复登录画面，只查看 |
| 开机后登录 | 核对 hy 的空密码框后提交一次密码，进入新的 Wayland 用户 session 6，活动且未锁定 | 8.82 秒恢复用户桌面，只查看 |

恢复时间由约一秒间隔的窗口状态采样计算，从首次观察到 `reconnecting` 到新 session 的
`viewing/frame_ready`；不是从触发命令开始计时的精确端到端耗时。四次均未执行手动重试。
每次登录前显式启用操作，恢复后均自动回到只查看。首次启用操作按钮返回后，状态尚未完成切换，
测试驱动拒绝发送点击；确认状态已启用后才发送，没有绕过输入状态检查。

重启前用户分辨率 1485×868，重启后的登录界面 1280×800，均为 100% DPI。
点击坐标按当前协商的屏幕尺寸和原生显示区域换算，不使用历史屏幕尺寸。此结果不替代多屏、旋转或混合 DPI 验收。

## 隔离与恢复

候选保存在 `/var/lib` 下独立测试目录，避免重启清理临时目录。
测试前备份原服务、配置和 GDM 文件哈希，设置限时恢复及开机后五分钟独立恢复保护；
仅创建本轮专属的服务覆盖和媒体启动单元。GDM 自动登录、账号及密码均未修改。
临时启动单元验证的是媒体进程开机登录能力，不替代正式安装包自启动、升级验收。

完成后关闭本轮远程窗口并退出本机隔离 Desktop，恢复原 Executor 服务（PID 2696，
`/opt/pixels-agent-bridge/run-executor.sh`，active/running，无 drop-in）。
原二进制、服务文件、应用配置、GDM 配置哈希一致；专属启动单元、恢复单元和候选目录已删除。
无候选进程、媒体运行目录或 Pixels Remote 虚拟输入设备残留；虚拟机停留在已登录、未锁定的 hy Wayland 桌面。
本机安装版未更新。凭据及原始桌面截图不进入验收文件。
