# 下载校验后自动启动安装

在线更新按钮改为“下载并安装”。原生 `download_update` 成功返回意味着安装包已
通过校验，前端随即调用 `install_update`，不再等待第二次点击或应用内确认弹窗。
Windows UAC 和 macOS 系统安装授权保持系统原有行为。

安装器启动成功后锁定按钮，等待原生命令退出应用。下载或校验失败时不启动安装；
安装器启动失败时显示错误和“重试安装”，重试通过原生下载入口重新校验已缓存文件。
更新操作期间禁止重新检查或重复启动安装。

验证：`npx playwright test tests/update-notice.spec.ts`，4 项全部通过：

- 发现更新的通知仍能打开更新页面。
- 即使进度已达 100%，也必须等原生下载校验成功才启动安装，且只启动一次。
- 下载或校验失败不启动安装，保留错误提示和后续操作入口。
- 安装器启动失败后可重新校验并重试，无额外应用内确认框。

测试使用真实 React 组件和模拟原生命令，未运行本机安装器，也不代表系统授权或
Company 的完整升级已实测。原生安装包校验和系统安装器启动逻辑未改动。
