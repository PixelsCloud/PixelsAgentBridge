# Windows 动态 DPI、分辨率与缩窗光标验收

日期：2026-10-20。基线 `2d21b63` 加本批 Windows 修复。使用 Windows 操作端和
90，不使用 XRServer。完整机器可读记录见同名 JSON。

## 修复的实际问题

观看中把 90 的临时副屏从 100% 改为 125%，系统已应用新 DPI，远程窗口仍保留
旧 session、`scale_milli=1000` 和已启用的输入。原生布局判断只有坐标、旋转和
monitor，遗漏 DPI；DXGI duplication 在 DPI 变化时也不一定返回失效。

现在枚举时保存 DPI，并把它与坐标、旋转、monitor 一起校验。采集在静态等待、
无视频额度等待及编码后检查布局，输入在发送前检查同一份布局。变化后结束旧
代次，沿用已有恢复流程。WGC 的 Default 桌面限制仍只用于 WGC，不能套到
DXGI 的安全登录桌面。没有增加认证、网络协议或用户配置。

## 验收结果

两轮都只创建一个有期限的 Parsec 副屏，主屏始终保持 1920×1080、100%。
操作端沿用已有 `f53f5803…`，修复后被控端 Desktop/helper 为
`4eb8c2742b4e3d0f1da46b85b02abb2bf29aee245b22429b05c79cb395efd9a5`。
本轮不是三平台统一的最终安装候选。

| 条件 | 实际结果 |
| --- | --- |
| 1920×1080 → 1280×720 → 1920×1080 | 初轮观察到重新连接、输入/首帧未就绪、新配置仍未就绪、两者就绪且默认只查看。稳定屏幕 ID 保持，旧 session 结束；恢复大分辨率后的点击落点通过 |

复用同一批截图核对绝对位置：箭头可见像素起点分别为 `(291,321)`、
`(385,321)`，视口目标点分别为 `(291.2,321.5)`、`(385.6,321.5)`，各方向
误差不超过 0.6 像素；这项是既有截图分析，没有再次发送输入或重跑界面。

修复后另有 125% 点击 `(3358,809)`、100% 缩窗点击 `(3358,808)`，对应预期
`(3359.25,809.25)`，各方向误差均不超过 2 像素。前述 Ctrl 由自有原生窗口
键事件发送并经目标实际按下状态确认；点击和最终光标检查使用真实鼠标输入。

自动恢复使用新的 `session_id`、`generation=1`；同一 session 切屏才增加
generation 数字。隔离标识是这对值，不能仅比较 generation 数字。新 session
只查看的现有行为保持。旧 session/错 generation 的协议隔离沿用既有
`input_wire`、`cursor_wire` 等验收，本轮没有重新跑已通过的共享协议矩阵。

Windows 媒体库 32 项通过、1 忽略，最终 Desktop 构建通过。编译 Cargo `-j10`，
进程及子进程亲和性最多 10 核，嵌套 CMake 为 1，无其他实际编译并发。

代码复核后，编码末尾改成只做布局检查，避免在尚未释放的 DXGI 帧内触发后备
切换。复核后的两项原生光标检查及 Desktop 构建单独留证；90 的界面实测固定
属于上面的 `4eb8c274…`，没有重跑已通过的界面用例。两份产物及源码哈希分别
保存在 JSON，不将复核后的产物标为已经过完整界面/最终安装验收。

## 保留的失败与驱动修正

- 修复前 DPI 变化后没有新 session/generation 是真实产品失败，保留记录。
- 初轮驱动只允许 generation 数字增加，把新 session 的 generation=1 误判。
  核对既有会话协议后改为比较 `(session_id,generation)`，没有因此修改产品。
- 最初夹具要求的 480 秒超过旧夹具 180 秒上限，未产生有效夹具；仅把测试
  夹具上限扩到 540 秒，并增加显示 lease 的停止文件，便于提前正常回收副屏。
  输入准备及轮询参数错误发生在有效动作之前，保留，不计作产品失败。
- 第一轮缩窗光标驱动仅投递移动消息，实际鼠标留在原点，像素差为 0；截图仍
  显示之前位置的光标。改为移动真实鼠标后只补这项检查，通过。没有修改光标
  渲染代码，也没有把旧失败改写成通过。

## 恢复与范围

两次显示 lease 均正常退出，主屏恢复且临时副屏移除。90 原服务命令与运行状态
恢复、按键恢复标记全零，自有任务和服务测试目录已移除。缩小分辨率导致 Windows
自动归一化了本测试的 DPI 缓存值，触发清理保护；随后仅清除本测试输出的
`DpiValue=0`，保留空缓存 key，不改其他显示设置。原始保护失败记录保留。

本机自有 Desktop/MCP 已退出、临时凭据槽撤销，原槽未变；受限私有测试副本保留。
没有更新本机或 90 的安装版，没有 push/COS 发布，2/8 小时测试没有启动。

本批 Windows 的动态 DPI/分辨率和缩窗光标缺口完成，后续不再重复；全平台条款
仍按证据分别保留。Mac/Linux 尚缺的同类动态布局实机边界不由 Windows 外推，
