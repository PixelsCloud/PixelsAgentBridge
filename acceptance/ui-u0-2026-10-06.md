  ARM 实机 Rust 1.95 编译通过。高层接口只覆盖部分 AX，缺失处可用同库底层绑定。

## 隔离决定与剩余验证

采用现有 desktop 可执行文件的内部 `--ui-worker` 模式，在可回收子进程里持有所有 UIA/AX
对象。不新增安装产品、不承载网络连接、不复用多个 MCP 的连接。父进程有界串行请求，
工作进程无响应时终止并回收，令其元素引用失效；不创建无限替补线程。
动作结果不确定时绝不自动重放。wait 在 Executor 采样，不在 helper 中长期占用输入队列。

U0 原型证明可行性。仍需产品级 watchdog、工作进程崩溃/签名归属/会话切换/多 MCP
隔离、资源上限、取消与不确定动作等测试，不能以本报告代替这些测试。

原始日志保留在两端 `.build` 下，不提交桌面内容。Windows fixture 已通过 stop 文件关闭；
Mac awake1 fixture 同样已发出 stop，fixture 另设5分钟自动退出。

## 扩展矩阵与预算修正

Mac backend7通过文本、checkbox、radio、table第二行、只读/secure/disabled拒绝及
重复名称检查，应用内部selected=1、radio=1、clicks=1。AXRow不提供AXEnabled，
仅该标准行类型从明确的AXTable/AXOutline父节点读取启用状态；其他未知属性保持未知。
Cell-based AppKit表格行没有名称，测试显式读取子单元格后取其父引用，产品不猜测名称。

Mac budget100/budget500各50轮：分别遍历122/522节点，无截断扫描；最慢100/302ms。
RSS分别14000→14208KiB、14224→14432KiB。默认返回列表均按32KiB预算截断。
Windows旧PowerShell回调fixture的100节点50轮句柄192→185、最慢4208ms；
500节点场景出现provider超时，不能算通过。改用原生WinForms回调fixture后继续验证，
保留之前失败事实。查询增加单元素UIA元数据批量读取，不预取ValueValue；
runtime ID仅作当前保留对象的等价比较，不作为公开引用或持久化身份。
依据：[Microsoft GetRuntimeId](https://learn.microsoft.com/en-us/windows/win32/api/uiautomationclient/nf-uiautomationclient-iuiautomationelement-getruntimeid)。

同级枚举逐步检查deadline；wait把剩余采样预算传给worker。
父watchdog对只读调用额外留250ms返回截断结果，真正阻塞仍回收worker；动作不加此宽限。
通用引擎新增循环/500节点/字节预算、权限撤销模拟、原生返回却无效果、owner/window释放测试。
14项worker/registry/engine测试和双连接IPC等待测试通过。未实际撤销用户TCC。

Windows1.2.23候选完整包生成成功，尚未安装；后续预算/性能修正会进入下一次正式构建，
版本计数不回退。90和本机仍为1.2.21，Mac仍为1.2.22。

Windows原生回调fixture资源测试通过：native500的50轮全部按3秒时间预算截断，
最慢3226ms，句柄191→184；native100有12/50轮时间截断，其余完成119节点，
最后一轮911ms，句柄191→191。并行编译负载下单次OS调用可超过预算，
外层watchdog负责终止真正阻塞的worker，不声称时间预算是原生API硬中断。
两组fixture均关闭；旧PowerShell回调fixture失败记录保留。这里不宣称500节点全遍历通过。

### Dependency and delivery audit

`cargo tree --locked --offline -p pab-desktop-control` with the Windows and ARM Mac targets confirms the product uses `uiautomation 0.25.1` and `accessibility 0.2.0`, respectively. Cached published manifests declare: UIAutomation Apache-2.0 / Rust edition 2024 (no explicit MSRV); Windows bindings 0.62.2 MIT OR Apache-2.0 / rust-version 1.82; accessibility and accessibility-sys 0.2.0 MIT / Apache-2.0 / edition 2018 (no explicit MSRV). The workspace requires Rust 1.95 and was built with that toolchain; absence of a dependency MSRV declaration is not evidence of older compiler support. Mac builds used the available Apple SDK; no lower macOS runtime compatibility was verified.

UIAutomation uses its pattern/input features plus the official Windows bindings; AX uses accessibility-sys/core-foundation underneath accessibility, with the existing Cocoa/Objective-C dependency graph. The new code does not enable the library's optional screenshot or logging features. `Cargo.lock` remains the authoritative full dependency graph. README English/Chinese disclose these libraries and licenses.

Compared with the previous final debug packages in `acceptance/2026-10-06.md`, Windows setup grows 27,743,248 → 28,268,045 bytes (+524,797, 1.89%); Mac ARM PKG 72,209,144 → 73,444,403 (+1,235,259, 1.71%); Mac Intel PKG 72,998,476 → 74,306,560 (+1,308,084, 1.79%). These are whole-package changes, not measurements attributable exclusively to a particular library.
