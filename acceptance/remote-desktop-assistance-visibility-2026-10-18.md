# AI 协助提示的原生可见性确认

日期：2026-10-18；修改基线 `084b674`。
[结构化证据](remote-desktop-assistance-visibility-2026-10-18.json) 包含源码与产物哈希、
修复前后四个原生对照和构建记录。

## 问题与修正

原来前端弹窗动画完成即调用 `desktop_assistance_displayed`，后端只检查调用来自
main WebView。若此时原生窗口已经隐藏或最小化，仍会向 AI 返回已显示。

后端现在先核对原生窗口可见且未最小化，否则返回 false，保留 pending。
前端在动画完成后尝试确认；尚不可见时等待窗口恢复并重试，确认成功后停止重试。
同一个请求最多一个未完成确认，旧请求的迟到失败不会改变新请求；投递失败和
用户按钮操作的错误分别保存。恢复只确认提示显示，不会自动打开远端窗口或启用输入。

## 验证

真实 Windows Desktop 使用独立配置与现有隔离凭据。本机安装版未替换。
以 CDP 函数断点暂停在实际确认 IPC 之前，仅隐藏/最小化该测试进程的主窗口，
恢复执行后从真实 MCP 查询协助状态，再恢复窗口。

| 情况 | 窗口不可见时 | 恢复后 |
| --- | --- | --- |
| 修复前，隐藏 | 错误地变为 displayed | displayed |
| 修复前，最小化 | 错误地变为 displayed | displayed |
| 修复后，隐藏 | 保持 pending | 自动确认 displayed |
| 修复后，最小化 | 保持 pending | 自动确认 displayed |

四次对照均保持 waiting，没有创建观看窗口、发送远端输入或自动完成协助。
请求最后取消，MCP 和独立 Desktop 退出。
