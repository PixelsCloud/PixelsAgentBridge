# Linux 注销后的新会话密码登录

日期：2026-10-17，基线 `454a7db`，完整候选沿用
[GDM 产品验收](remote-desktop-linux-gdm-product-2026-10-17.md) 的 Desktop/Executor。
本轮补测注销后的新会话，不修改生产代码、不重新编译、不覆盖安装版。
原始观察和产物哈希见 [机器记录](remote-desktop-linux-logout-login-2026-10-17.json)。

## 测试与结果

用户已授权 Linux 虚拟机锁屏、注销和会话切换。前置检查确认只有一个 seat0
图形会话 23，GDM 未开启自动/定时登录，无运行时配置覆盖。建立正式 Windows
独立远程窗口后，仅终止这个图形会话；现有 SSH 和系统服务不作为注销目标。

旧会话消失后，GDM 自动创建 Wayland greeter c14。等待 SessionManager 与
DisplayConfig 就绪、监督 helper 归属 UID 128 后，同一窗口自动显示用户列表。
显式启用操作，Enter 选择用户；查看实际密码框后，通过原生输入只提交一次密码。

系统随后创建新的 Wayland 用户会话 **191**，UID 1000、active、unlocked；原会话
23 已不存在。此时恢复脚本未执行、回滚计时器未触发，未发送任何恢复登录或
解锁输入。正式窗口自动显示新桌面，媒体 session 已改变并恢复仅查看；独立
进程检查确认 helper 从 greeter UID 128 切回用户 UID 1000。

在新会话重开自有测试窗口后，显式启用操作：

- 单击产生一次按下和一次释放，中心定位误差每轴小于 1 像素。
- Ctrl 产生一次按下和一次释放，无残留按键/按钮。
- 关闭操作后再次向自有原生窗口发送点击，远端计数不变，输入 worker 已退出。

这些观察证明本轮实际密码登录、会话交接和新会话的基本操作通过。

## 恢复与剩余项

恢复脚本已适配注销：不再激活或解锁已经消失的旧会话，也不会自动输入密码。
关闭自有窗口后恢复原 Executor，15 个一秒样本均保持新会话 191 active/unlocked。
安装程序、应用 TOML、systemd unit、GDM 配置哈希保持；没有改变自动登录或账号
密码。临时覆盖、媒体 runtime、进程、输入设备和远端目录清零，Windows 私有
profile 和凭据副本清理。现有安装版在新登录会话中正常自动启动，未被替换。

W5 仍未关闭：上述图像差异、开机未登录、实际多屏和安装升级尚待验收。
