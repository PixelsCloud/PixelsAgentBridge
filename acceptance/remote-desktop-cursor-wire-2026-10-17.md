# 独立光标协议与可靠传输：基础阶段

日期：2026-10-17；修改前基线 `b37bc0a`。本阶段完成光标元数据和可靠流编解包，
尚未接入正式会话、helper、系统采集或原生渲染。**LT-03.5 保持未完成。**

## 实现

- 使用现有 PabFrameReader/Writer；不增加连接、认证或设备占用规则。
- 头部绑定 session、generation 和严格递增 sequence。新流必须先取得图像，
  才能显示或引用；切屏后的新流不能引用上一代图像。
- 图像改变时传一个新 ID 和像素；普通移动/隐藏只传元数据，引用最近的图像。
  图像 ID 只能递增，不能引用未知或较早图像，也不形成无限增长的 ID 缓存。
- 图像最大 512×512。支持预乘 BGRA 和 AND/XOR BGRA，后者保留传统反色光标
  语义；最大载荷 2 MiB，分块仍为 64 KiB，不扩大通用传输的单帧上限。
- 热点属于图像像素；位置属于当前屏幕的桌面坐标，允许负原点。图像约定已经
  按可见桌面方向排列，后续渲染不能重复旋转。
- 静止光标允许长期没有更新；收到数据后，头部及完整载荷都有时限。中途取消、
  超时或失败会废弃该光标流，不能把剩余像素误读为新头部。
- 像素不进入 JSON 或 Debug 日志。没有改动现有远程桌面 schema v2、能力公告、
  安装配置、认证、视频与输入路径。

## 已运行的验证

Windows 本机，Cargo 8 jobs，原生构建环境限制 1 job，测试线程 2；两条编译
命令顺序执行，没有并行编译。没有替换安装版或修改远端机器。

```text
cargo test --locked -p pab-protocol --lib -j8
cargo test --locked -p pab-remote-desktop --lib --test reliable_sessions -j8
```

- protocol：68 项通过，其中新增图像尺寸、格式长度和热点边界检查。
- remote-desktop 单元测试：6 项通过，包含原有占用、账号变化和输入释放规则。
- reliable_sessions：17 项通过，包含新增 6 项光标测试。使用真实本地 Iroh/QUIC
  可靠流和生成像素，覆盖最大 2 MiB 图像、负坐标、移动不带像素、隐藏、替换、
  未知/旧图像 ID、重复序号、错误身份/代次/版本、非法尺寸/热点、半包超时和
  取消、静止等待、写入前校验、写入失败后的流废弃。
- 光标流失败或取消后，同一连接的另一个通用流仍能收发。现有视频和输入的
  11 项可靠会话测试继续通过。

日志保存在工作树 `.build/remote-desktop/pab-protocol-cursor-tests.log` 和
`pab-remote-desktop-cursor-tests.log`。测试后仅对新增 Rust 文件运行 rustfmt，
没有改动测试过的语义。上述结果不代表真实设备光标、弱网或三平台原生渲染已通过。

## 后续接入顺序

1. 在现有授权会话内协商光标能力并打开独立可靠流，绑定同一个 helper 和视频
   generation；关闭、切屏、账号切换时回收，保留单观看者规则。
2. 采集端保留一个最新快照，视频静止或缺少展示额度时仍能更新光标。平台明确
   返回已嵌入视频、独立光标或不可用，避免双光标；不能直接假设 DXGI 纹理总是
   不含光标。Mac/Linux 当前嵌入模式要与独立模式一起调整。
3. 三平台原生渲染添加独立叠加、热点、缩放和裁剪，处理 AND/XOR、屏幕边缘、
   负原点、旋转、多 DPI、隐藏、切屏和会话恢复。已隐藏/旧代次光标立即清理。
4. 在普通桌面、静态画面、多屏和锁屏登录上验收；Mac 按本轮单屏条件执行。
