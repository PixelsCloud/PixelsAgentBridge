# Debian 11 在线安装及远程使用验收

日期：2026-10-15。结论：官网已发布的 **Linux x86_64 V1.0.2** 通过 Debian 11 验收，无须重新编译或重新发布安装包。Debian 已实际验证的版本为 **11、12**；Debian 12 的既有结果见 [前一轮记录](../linux-ubuntu2004-2026-10-15/README.md)。

## 环境和安装入口

使用独立的 `debian:bullseye-slim` 容器，在容器内运行真实 systemd，限制为 2 个 CPU。Debian 11 用户空间为 glibc 2.31、Python 3.9.2、OpenSSL 1.1.1w、cryptography 3.3.2；没有替换 glibc 或升级到 OpenSSL 3。

```bash
curl -fsSL https://agent.rgaa.vip/install.sh | bash
```

测试前不存在 Python。官网脚本自动安装 Python 及签名验证依赖，再从官网查询版本、下载 COS 正式包并验证签名、大小、SHA-256 和运行库。

Debian 默认软件源在准备环境时出现部分 `.deb` 返回 404；测试环境改用 Debian 官方 `20260518T000000Z` 的带签名软件源快照，保留包签名校验，关闭快照元数据的有效期检查。此变更仅在隔离测试镜像中，未修改产品安装脚本。因此，结论覆盖软件运行及安装兼容性；用户自己的软件源若不可用，仍需先修复软件源。
