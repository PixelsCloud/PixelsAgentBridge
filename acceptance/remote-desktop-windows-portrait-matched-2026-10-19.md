- 只强制终止采集代理，原代理与用户采集子进程均回收；正式窗口重建会话并恢复画面/输入就绪，仍默认只查看。

## 产物一致性问题

此前暂存脚本仍使用旧 `service-artifacts/pab-executor.exe`，不含独立光标能力字段
和 helper 注册入口。它可以提供视频/输入，但没有建立独立光标通道。新诊断轮次
还出现本地 Desktop 已更新、远端 Desktop 未更新的情况，不能据此判定新源端日志无错误。

已改为统一选择当前 `desktop-check/debug` 的 Executor、Desktop 与 worker，
先检查 Executor 能力标记、两端 Desktop 哈希相同，再记录 manifest 并校验远端上传哈希。
本轮 Executor 为 `252223ac81648750057610a66d8df12dafc479f3bde1b02755bacbed44e9f009`，
两端 Desktop 为 `ab888c15d5ed16d26767de2d9ea0ab217bb2eaf7cfdd62ec89c5e6e9304010c7`。
旧失败记录保留在[产物审计](remote-desktop-cursor-artifact-audit-2026-10-19.json)，
不再将其描述为当前版本光标缺陷。混合新旧服务端的完整兼容性也未因此判定通过。
