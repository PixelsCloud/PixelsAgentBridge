# Mac 独立窗口光标复测

2026-10-18，源码 `b2a7f0c`。用户通知 Apple 恢复可用后执行；单屏
1920×1080、100% 缩放，Apple M4 / macOS 27.0.1 → Windows 90。
本轮验收 Mac 操作端对已有 Windows 独立光标源的显示及故障隔离，
不关闭整体 W2/W4/W7，不代替 Mac 被控端、锁屏登录或性能测试。

## 宿主复测

此前锁屏时超时的失败记录保留。相同构建的 `macos_host_check` 在解锁后的
GUI 会话通过，任务 `feaee517-d2d0-4c6d-ae9c-0b50748d6abe`，退出码 0。
硬/软解码 × 普通/奇数尺寸共四组，每组 8 个生成视频帧；隐藏窗口不确认呈现、
静帧恢复、待处理帧取消、彩色/AND-XOR/移动/隐藏/清除光标 ACK、
光标更新不增加视频呈现数、窗口关闭后旧句柄拒绝提交均通过。

## 真实产品窗口

复用已保存凭据和现有认证，通过 AI 协助请求打开隔离候选 Desktop 的独立窗口。
候选源码二进制 SHA-256 为
`ef0119267c6bf709f279d0d868eaec7d6894225cbbaaa7186d2799fed3f73170`，
签名后为 `797f3e7160189bda4f37ad053276e8339fa44ddcd5b76a624b95e0a1591dfee9`。
未替换安装版或两个已授权的固定测试 App，未调整 TCC。

- 默认只查看；明确启用操作后，Mac 图像区域的鼠标移动到达 90 自有测试窗口。
  四区源坐标依次为彩色 `(797,550)`、系统箭头 `(471,550)`、
  AND/XOR `(1122,550)`、隐藏 `(1449,550)`。源端探针分别确认区域和可见性。
- 产品窗口截图显示系统箭头、彩色和黑白/透明/反色光标；隐藏区域无残留。
  截图为 JPEG quality 95，仅作为形状、位置和清除的窗口证据；不能据此声称
  颜色逐像素完全相等。精确 GPU 比较沿用上一记录的生成纹理检查。
- 关闭窗口后 AI 协助回到 waiting，重新打开得到新窗口且默认只查看。
  再启用操作，新的光标源恢复显示。没有沿用旧窗口或失效句柄。
- 第二轮仅结束暂存程序的光标 worker，保留视频与输入。
  同一窗口仍 active，远端测试色条继续变化，鼠标继续到达隐藏区。
  光标原区域 40×45 像素全部恢复平坦背景；色条前后最大通道差 153。
  第一轮故障截图拍摄时测试窗口已到期，**弃作清除证据**；第二轮重新运行
  测试窗口，在其仍存活时注入故障并截图。

通过独立 AppKit 诊断读取当前系统光标图像（不采屏、不注入输入）：

| 状态 | 系统光标图像 |
| --- | --- |
| 只查看 | 非透明，21,297 个非透明像素 |
| 启用操作且位于远端图像 | 1×1 透明，0 个非透明像素 |
| 停止操作，鼠标未移动 | 恢复非透明 |

此诊断使用 `NSCursor.currentSystemCursor` 只读检查，返回图像表示尺寸不代表
屏幕指针的显示尺寸。诊断二进制已删除；它不属于产品依赖。
