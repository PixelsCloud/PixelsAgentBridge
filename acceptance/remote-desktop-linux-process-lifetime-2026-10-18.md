# Linux 媒体进程生命周期与持续观看

2026-10-18，基线 `780fa76`。本轮检查 Windows→Linux 正式窗口的持续连接；
不更换本机安装版，不修改客户配置或既有网络鉴权。

## 定位与修正

Linux `process_identity` 返回的是进程操作使用的 pidfd 租约标识，固定有效期为
600 秒。旧媒体 helper 和 compositor 环境观察将该标识长期保存，再与后续
`process_identity` 的结果比较。到期重新生成标识后，存活进程也会被判为已替换；
这会关闭媒体 IPC，或使 supervisor 重启媒体 helper。

增加仅供本地媒体使用的 `LinuxProcessWatch`，持有原进程的 pidfd；重复观察
共享同一引用，最后一个持有者释放后关闭 fd。存活判断、原生账号读取和 compositor
描述符复制均绑定该句柄；仍核对活动本地图形会话、UID 和 kernel IPC peer。
Windows/macOS 分支与进程操作 token 的原有有效期保持。

增加会话观察错误、helper 断连及身份观察失效日志，不记录输入、帧内容或凭据。
Linux `pab-os-control` 的 18 项测试通过，其中新增两个用例验证：

- 强制跨过操作租约期限后，旧操作 token 被拒绝，而同一存活媒体进程仍有效。
- 不同进程不匹配；进程真正退出后，存活检查、账号读取和描述符复制均拒绝。

完整 Linux Desktop/Executor 构建通过，Cargo 3 jobs、嵌套 native 1 job。
独立监测发现其他项目启动 10 jobs 后暂停自有容器，结束后继续；监测为周期采样，
不以此宣称零时间的并发重叠。新版持续观看正在独立验收。

同一源码新构建的 Executor 测试二进制在 Linux 实际用户会话中额外通过四项
媒体 IPC 回归：有界二进制传输与关闭回收、启动/静态采集取消、静态采集期间
输入与关闭释放、supervisor 优先与退出后后备。测试使用独立临时端口和进程，
未替换安装服务，执行结束后远端测试文件已清理。

13.56～14.70 FPS（平均 14.33），各轮命令、PTY 和 4 MiB 上传下载通过。

- 09:48:17.197039 UTC：helper PID 42007 启动。
- 09:58:17.403653 UTC：Executor 记录媒体本地 WebSocket 关闭。
- 09:58:17.436725 UTC：supervisor 回收 helper。
- 09:58:17.443243 UTC：在同一用户会话 2 启动 helper PID 43986。

测试前后测得远端快约 20.2 秒，本机错误与远端事件按该偏差对齐。
