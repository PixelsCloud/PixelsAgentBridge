# 客户端移除繁体中文

Windows 1.3.14 已包含本项改动并发布 COS，见[发布记录](../windows-close-release-20261021/README.md)。下文开发阶段的“未发布/暂停”描述按当时状态保留。

桌面客户端只支持简体中文和英文：移除语言选项、繁体文案字典、Ant Design 繁体语言包，以及终端、账户、设备菜单、macOS 权限与协助提示中的繁体分支。Windows、macOS、Linux 使用同一前端；Android 原本即只有简体与英文。

旧 `pab.language` 中文变体设置迁移为 `zh-CN`，保留其他偏好。系统语言为 `zh-TW`、`zh-HK`、`zh-Hant` 等时默认显示简体。托盘仍能接受旧窗口的 `zh-TW` 参数并显示简体；不再提供繁体文案。

主工作区与远程桌面功能工作区均完成同范围修改，保留各自其他正在进行的改动。根目录中英文 README 和 Desktop README 已同步更新。命令输出的 Big5 解码继续按数据编码测试，不属于界面语言支持。

## 验证

- 功能工作区前端构建、主工作区 TypeScript 检查通过。
- 6 个相关界面测试文件覆盖 86 个不同用例：首次 84 项通过；两项已有权限状态断言仍期望 `Normal`，而改动前程序已经显示 `Granted`，更新断言后仅补跑这两项并通过，未重复其余 84 项。
- 新增旧繁体偏好迁移、语言选项仅有两项、托盘使用简体，以及三种繁体系统语言默认简体的浏览器验证。
- 没有替换本机已安装的 Desktop，也未发布 COS；本批是源码、构建与回归验收。

源码指纹与验证范围见 [result.json](result.json)。本地改动前备份与原始日志位于 `.build/remote-desktop/client-language-20261021/`。
