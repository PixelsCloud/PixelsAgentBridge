# Apple 注销后系统登录：真实产品窗口

日期：2026-10-19。Apple M4 / macOS 27.0.1，单屏 1920×1080。

**注销后 LoginWindow 的密码登录及画面恢复通过。** 通过隔离 Windows Desktop
的正式独立观看窗口执行正常注销，系统控制台 UID 从 501 变为 0，实际画面显示
系统登录界面。显式启用操作后，按用户本次授权点击系统屏幕访问提示的“允许”。
确认提示消失、密码框可见后，通过观看窗口提交一次登录密码，控制台恢复 UID 501，
实际画面显示用户桌面及重新打开的窗口。

观看窗口在用户会话变化时自动重连，恢复的新视频 session 为
`25ada249-24fb-4d6c-844e-19acae6f1407`，generation 1，解码器仍为
`d3d11_hardware`，画面及输入就绪，`input_enabled=false`，默认回到只查看模式。
本轮未测量持续帧率，配置的 15 FPS 不作为实测帧率。

测试沿用同一个已授权 App 路径、签名身份和二进制，没有重装或重签名。
本次实际观察到 LoginWindow 会话另外出现直接访问屏幕的系统确认；此前 Aqua
会话的权限状态不能替代这次确认。本次仅证明确认后登录可用，尚未证明下次
注销或重启不会再次提示。没有修改 TCC 数据库或自动代替用户批准权限。

隔离测试的 launchd 管理脚本原先尝试从 `user/0` 推导登录域，实际 LoginWindow
域为 `loginwindow`。本轮修正了测试脚本，并在该域启动候选 helper，随后登录成功。
原安装的 LoginWindow LaunchAgent 此时已经存在；这项测试修正不等于安装包启动
链路已经完成验收，也没有据此修改产品代码。

结束后关闭观看窗口与隔离 Desktop/MCP，通过 stop 标记让独立 watcher 恢复
原服务，随后核对安装文件、配置及设备密钥哈希不变。原服务 PID 88603 正常运行，
测试 helper/采集进程已退出，私有 stage 和回滚任务已清理；Apple 保持登录后的桌面。
本机安装版未修改。凭据仅由本机加密文件读入内存，未写入记录或 Git，未重复提交。

证据见[机器记录](remote-desktop-macos-logout-login-2026-10-19.json)，截图仅保留在
本机忽略目录，版本库记录文件名和哈希。此结果不包含开机未登录、FileVault 预启动、
Mac 多屏或 Mac→Mac，也不关闭整个 LT-07。2 小时及 8 小时测试按用户要求暂缓至晚上。
