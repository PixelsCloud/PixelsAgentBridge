# Windows 普通应用输入、注销与重启登录

日期：2026-10-19；源码检查基线 `655773f`。本轮使用隔离 Desktop 和 90 的临时候选服务，
未更新本机安装版。具体二进制哈希、探针结果和任务编号见[结构化记录](remote-desktop-windows-input-login-2026-10-19.json)。
本轮实际枚举到一块 1920×1080、100% DPI 显示器，不用历史双屏结果替代当前条件。

## 普通应用输入

通过正式远程桌面原生显示面发送输入，目标是本轮创建的经典记事本及唯一临时文件。
只读探针校验窗口所属 PID，使用有超时的窗口消息读取选区和滚动位置；没有读取用户其他编辑器内容。

| 动作 | 实际观察 |
| --- | --- |
| 单击 | 选区 `[3,3]`，只放置光标，没有出现双击选词效果 |
| 双击 | 选区 `[0,11]`，正确选中首词 |
| 拖拽 | 选区 `[0,25]`，结束后无鼠标键残留 |
| 滚轮向下三个刻度 | 首个可见行从 0 变为 9 |
| Ctrl+A | 选区 `[0,5922]`，选中全部测试文本 |
| 输入固定测试标记 | 文本长度 18，探针确认与预设标记相同；未记录用户输入 |
| Ctrl 按下后失焦 | 远端先观察到 VK_CONTROL 按下，失焦后变为空集合 |
| Ctrl 按下后关闭窗口 | 远端先观察到 VK_CONTROL 按下，关闭后变为空集合 |

本轮没有对普通应用观察到重复操作，但不等于排除了所有首击边界。
记事本窗口在早期探针之间发生位置变化，不能宣称全程排除外部操作，也不把选区结果当作底层消息计数。
[未初始化线程活动窗口的诊断失败](remote-desktop-windows-input-queue-2026-10-18.md)仍保留，
没有采用点击去重、强制前台或 `AttachThreadInput` 作为猜测性修复。

原持续探针在两个样本后没有继续输出，改用独立、有超时的探针确认上述结果。
记事本到时关闭后，一轮释放探针因窗口身份失效被拒绝，未计为通过；随后使用独立键状态探针重做，
确认真实按下和释放。最终测试记事本进程、唯一临时文件均不存在。

## 登录链路

- **锁屏**：正式窗口发送 SAS，进入密码界面并登录，恢复新会话且默认只查看。
  初次自动化驱动曾在 SAS 恢复后的“仅查看”状态发送本地输入消息，产品拒绝发送，密码框仍为空；
  检查状态并显式启用后才实际提交一次密码。后续驱动增加状态及一次性提交检查。
- **注销**：console session 2 注销后进入 session 3 的 Winlogon，原窗口自动恢复画面；
  显式启用操作、SAS、提交用户名及一次密码后回到 Administrator 桌面，默认只查看。
  登录界面的中文输入法会先组合用户名，需要提交拉丁候选后再 Tab 到空密码框；此过程有截图核对。
- **真实重启**：系统启动时间从 `2026-10-15T15:55:05.5000000Z` 变为
  `2026-10-19T03:15:21.5000000Z`。未登录时 console user 为空，候选 SYSTEM supervisor
  和 Winlogon helper 已自动启动。手动重试后看到登录界面，实际提交一次 Administrator 密码成功，
  回到用户桌面且默认只查看。
- **重启自动重连失败**：旧候选在设备离线期间收到控制服务 `NotFound`，立即进入 failed，
  没有用满既有 120 秒恢复窗口。因此这一轮不能记为重启自动恢复通过。
  后续修复仅允许曾实际显示画面的远程桌面窗口，对这种设备查找失败进行限时重连；
  初次查找、认证和权限拒绝不扩大重试，通用连接策略保持原样。修复后复测结果见下节。

首次重启画面已显示 StreamTest 的用户名/密码错误提示，发生在本轮发送任何重启登录密码之前。
本轮关闭该提示后输入已授权的 Administrator 身份，没有修改系统自动登录配置。
用户随后提供的 StreamTest 凭据仅保存在本机 Windows DPAPI 加密文件中，不进入仓库或截图证据。
