# Windows 正式窗口连接 macOS：首帧与关闭

日期：2026-10-17。工作树基线 `726bb9d`。本轮没有修改生产代码。

Windows 隔离 Desktop 通过既有账号、设备密码和通用可靠传输连接 Apple，
从真实 AI 协助提示打开正式独立窗口。原安装版返回明确的 Unsupported，
原因是没有远程桌面媒体后端；不是用户未授予系统权限。

候选 Executor 以 4 jobs 完成 release 编译。临时 LaunchDaemon 使用独立数据库，
仅复制现有设备身份密钥和 device_access 记录，不复制历史任务、输出或账号，
不修改安装版数据库。旧 settings.env 只作文本解析，生成隔离 TOML；没有执行
配置内容。复用已经授权的固定路径、固定签名候选 helper。

切换前启动独立 8 分钟回滚进程，候选最多运行 7 分钟；原服务暂时停止，原安装
文件全部保留。首次候选连接因临时父目录继承 umask 077 而无法启动用户 helper
（EX_CONFIG 78），修正临时父目录遍历权限后通过。凭据目录保持 0700、密钥 0600。

## 实际结果

- 正式窗口显示 Apple 当前桌面，屏幕 `29C1`、1920×1080；人工检查了窗口截图。
  截图只留在受限、gitignored 的本地验收目录，不随记录发布。
- 原生显示报告首帧后启用操作按钮可用；协助状态进入 `active`。
- 关闭真实原生窗口后，协助状态回到 `waiting`，没有误报完成；随后取消测试请求。
- 全程只查看，没有发送远端键鼠输入，没有观察到新的系统授权请求。
- Windows 测试进程退出；Apple 原服务恢复并重新连通。安装版程序、启动脚本、
  配置和身份密钥的哈希不变，原设备认证记录与隔离副本一致。
- 候选 Executor/helper/worker 进程为 0，三个临时 launchd 作业均卸载；临时服务
  目录及其中的身份和认证副本已删除。原服务恢复 PID 为 57022。

完整产物哈希和恢复任务 ID 见 [机器记录](remote-desktop-windows-to-macos-2026-10-17.json)。
