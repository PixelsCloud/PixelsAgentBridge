## 活动中的 AI 协助

全部从实际协助提示打开正式原生观看窗口，确认画面与输入通道就绪、默认只查看，
再实施操作；不是直接改数据库中的请求状态。

| 情况 | 实际结果 |
| --- | --- |
| 工具取消 active 请求 | cancelled/requester_cancelled；完成按钮消失；原窗口、视频 session 和只读画面保留；旧 ID 的完成调用被拒绝 |
| 强制结束请求方 MCP | 约 29.46 秒后 cancelled/requester_unavailable；复用的原观看窗口继续显示，没有误记完成 |
| 强制结束 active Desktop 并启动新实例 | 约 29.68 秒后同一请求重新显示、waiting、无 window_label；没有自动观看；显式点开后建立新 session，默认只查看 |
| active 请求到达 15 秒有效期 | expired/expired；完成按钮消失，原窗口和视频 session 保留 |

约 30 秒延迟来自现有参与者租约，不是即时进程死亡检测。测试结束两代 Desktop、
请求方进程和本轮媒体进程已退出，39100 端口已释放。
新增可复用的[真实进程验收脚本](../experiments/remote-desktop/assistance_active_acceptance.py)，
配套脚本只控制显式启动的隔离 Desktop 调试端口；没有发送远端键盘或鼠标输入。

## 从实际设置页面切换服务器

使用没有 `--config` 参数的隔离 Desktop，仍从其自身目录读取 TOML，实际点击设置页
保存按钮。开始时两输入框为空，已登录且协助 active。保存回环测试地址后：

- 约 5.88 秒内旧请求取消、旧观看退出，本轮媒体进程消失；旧 MCP 查询及三种旧 UI 请求动作均被拒绝。
- 旧账号变为未登录、active_slot 与待退出列表清空；本轮独立测试凭据槽被删除。
- 正常退出后重新启动，页面保留客户地址，账号未登录、没有旧请求或自动观看。
- 从实际页面清空覆盖值并再次启动，输入框恢复为空，旧账号仍未登录，没有恢复旧协助。

Windows 账号令牌保存在按服务/slot 命名的系统凭据库。测试为该隔离资料创建了新的
随机 slot，令牌只在系统 API 内存中复制，未写入日志/文件或传入命令行。
设置保存只删除测试 slot；本机原账号文件及原凭据条目的存在性/修改时间均保持不变。
临时 slot 与账号/设备凭据副本已清理。API 依据
[CREDENTIALW](https://learn.microsoft.com/en-us/windows/win32/api/wincred/ns-wincred-credentialw)、
[CredReadW](https://learn.microsoft.com/en-us/windows/win32/api/wincred/nf-wincred-credreadw) 和
[CredWriteW](https://learn.microsoft.com/en-us/windows/win32/api/wincred/nf-wincred-credwritew)，
slot 命名核对了本地 keyring 3.6.3 源码。

回环地址有意不可达，本项验证配置与旧身份隔离，不代表在客户新服务器登录/观看成功。
也没有登录另一个实际账号或验证安装包的重启按钮。
测试恢复私有账号文件时回退了其 revision，后续同步提示 pending；仅提高该私有
revision 后连接恢复。该无效测试准备尝试不算产品故障或通过；正常用户配置没有回退。

## 90 的 100% / 125% 双屏

用户改为只用 90，XRServer 未参与本轮动作验收。90 原来只有一块 Mi TV，
1920×1080、100%。通过已有 Parsec 驱动增加一块五分钟租约的虚拟屏，位于
`(1920,0)`、1920×1080，在 Windows 设置中仅将它改为 125%；原主屏仍为 100%。
系统快照和产品屏幕列表分别确认了两屏的真实缩放，产品使用 H.264/D3D11 原生显示。

切至虚拟屏、再切回主屏，generation 从 1→2→3，两次切换均默认只查看。
每屏在 25%/75% 位置各点两次，共四次，每次各一个按下/抬起；其他屏幕计数不变，
鼠标和 Ctrl 均未按住。实际位置 `(2400,269)`、`(3360,811)`、`(480,269)`、
`(1440,811)`，最大误差 1 个源端像素。原生观看区域为 1100×688，包含留白映射。

本轮没有新增混合 DPI 的窗口缩放、竖屏、光标像素比较或观看中途调整 DPI 测试。
此前竖屏和窗口尺寸的通过记录不能直接合并为所有混合 DPI 条件都通过。

原设置窗口的通用 UI 查询返回 stale_element，通用聚焦批次在点击前被拒绝，通用
显示器输入也明确未发送点击。随后使用已选中的原用户上下文、限定自建设置窗口和
点击位置的普通系统输入及 UIA 完成缩放；没有强制激活或权限绕过。这些旧工具错误
未修复，也没有计为远程观看窗口的输入失败。
