# Apple 正式 helper 与 Windows 独立窗口生命周期

日期：2026-10-18。范围：Apple 已解锁的单屏桌面，Windows 隔离 Desktop。
原始结果的脱敏摘录见 [JSON](remote-desktop-macos-helper-lifecycle-2026-10-18.json)。

## 本轮通过的功能检查

- 从 AI 协助弹窗打开正式独立窗口，两轮均取得 Apple 1920×1080 桌面首帧。
- 实际解码状态为 `d3d11_hardware`，默认只查看；未发送远端键鼠输入。
- 正式 App 的 `--session-helper` 启动独立视频与光标子进程，两者的 PPID 都指向 helper。
  使用产品匿名管道，没有使用此前留存进程的 FIFO 测试转接器。
- 每次正常关闭窗口后，协助状态从 active 返回 waiting，两个媒体子进程均退出，
  helper 保留。第二轮采用新的窗口与视频会话 ID，成功重开。
- 人工查看第二轮本地截图确认桌面画面及箭头可见；本轮没有做光标像素、形状切换、
  隐藏或视频是否重复合成光标的对照，不能据此关闭完整光标要求。
- 测试后 Apple 原服务恢复运行、安装文件哈希不变；远端临时 helper、回滚任务及
  私有测试目录已清理。没有修改已安装 App，也没有再次申请系统权限。

## 保留的失败轮次与测试修正

初轮使用旧 Executor（`4d0ee1d6…`）与新版测试 App，窗口能出图但没有独立光标
进程。旧 Executor 构建早于配对光标协议接入；随后同步当前源码，校验关键源文件
哈希，以 4 个 Cargo jobs 构建新 Executor（`e813b153…`），耗时 1 分 19 秒。
新组合的两轮均观察到真正的 `--media-worker cursor 1` 子进程。

初版检查用字符串包含 `cursor` 判断进程，误匹配了视频参数
`desktop-separate-cursor`；已改为匹配完整操作前缀，初轮不算光标通过。
初轮第二次打开未找到窗口。测试使用相同弹窗内容，可能点中 UI 尚未刷新的旧请求；
改为每轮独有内容定位后两轮通过。没有足够证据把初轮失败判为产品窗口重开缺陷。

初轮通过候选 Executor 执行恢复命令，终止候选服务时中断了自身任务，造成短时
离线；预先注册的独立回滚恢复了原服务，随后验证并清理。第二轮改为写入停止标记，
由独立 watcher 恢复原服务，恢复与清理均成功。未重放中断的恢复任务。

`.build/remote-desktop/mac-source-product-d65086f7ff00/data`，ACL 仅当前用户与 SYSTEM。
