# C1 命令输出编码：源码回归

基线 1ca5458。共享 `encoding_rs` 解码已接入 MCP 即时预览、分页读取、Desktop 初始历史和
增量输出。UTF-8 默认；可显式选择 GBK、GB18030、Big5、UTF-16LE/BE。选择仅影响本地显示，
远端命令/原始字节/请求去重不变，不自动猜测本地代码页。

非最终片段的末尾字符不消费，next_offset 指向其首字节；最终坏字节显示替代符并报告。
MCP include_base64 返回未筛选的 [offset,next_offset) 原字节，contains 只筛当前文本片段。
任意起点/尾读的字符边界明确未验证；UTF-16 显式奇数偏移拒绝，尾读/保留范围起点向前对齐。
Desktop 切换编码从原任务重读，旧请求回包不能覆盖新选择，不再次提交命令。
