# Linux 注销登录：自动恢复回归

日期：2026-10-17。开发分支 `feat/remote-desktop-v1`，修复基线 `4df7f93`。
本记录只覆盖 Windows 正式独立窗口连接 Ubuntu GNOME Wayland 虚拟机。

## 修复前实测

运行 `formal-linux-login-7e509e7eddaa`：从用户会话 191 注销，进入 GDM 会话
c15，随后在正式查看窗口内输入一次密码，成功进入新用户会话 281。
但自动恢复在两个切换阶段均停止，需要手动重连两次，因此自动恢复验收失败。
旧策略最多重试六次；新桌面暂时无法列出屏幕时，会过早耗尽次数。

测试观察器另有一次 4 秒 D-Bus 查询超时；只重新观察同一登录界面，没有重复
注销操作。后续确认 GDM 与媒体 helper 就绪。观察器现捕获单次查询超时，在
原有总时间限制内继续只读观察，不改变产品行为。

恢复后生成图案上的中心单击和 Ctrl 均各收到一次按下/抬起，无残留按键。
基线截图被无关本机窗口遮挡，不能用于画质比较，保留为未测量，不能记为通过。
测试后原安装程序、TOML、systemd unit、GDM 配置均保持原哈希，原服务恢复，
新会话 281 保留；临时媒体进程、虚拟输入设备和隔离 profile 已清理。

## 产品修改

对现有分类为可恢复的错误，改用从首次失败起最多 120 秒的重试窗口。
退避从 250 毫秒增长至 2 秒；失败次数不再提前结束恢复，也不延长截止时间。
连续显示达到现有的 5 秒稳定条件后，下一次故障获得新的恢复窗口。
用户明确重试也会重新计时。关闭窗口仍可取消整个恢复任务。

权限、认证、占用等原有不可恢复错误保持原分类；每次新媒体会话恢复为只查看，
不重放旧输入。120 秒限制决定是否启动下一次重试，各次连接仍有原有超时。

三项确定性单元测试通过：超过六次暂时失败仍继续等待；慢失败与重复失败不
延长截止时间；极大计数不会造成移位溢出，且退避仍不超过 2 秒。
