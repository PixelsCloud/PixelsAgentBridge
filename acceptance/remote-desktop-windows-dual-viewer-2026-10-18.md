# Windows 正式窗口双屏与热拔恢复

日期：2026-10-18；基线 `097dd77`。沿用用户允许的 90 临时 Parsec 副屏，
不安装驱动、不修改原物理主屏配置。两屏均为 1920×1080、100% 缩放，
原主屏位于 (0,0)，临时副屏位于 (1920,0)。

使用正式独立 viewer、既有可靠连接和 Desktop 内嵌媒体路径。
新增测试辅助程序 `experiments/remote-desktop/windows_two_screen_fixture.cpp`：
显式参数才启动，最多 180 秒，要求恰好两屏；仅在自身窗口绘制不同颜色并统计
鼠标与 Ctrl 事件，无全局钩子、文本采集或输入注入。正常 ShowWindow 启动，
不覆盖此前“不激活启动且线程没有活动窗口”的未解决边界。单核编译，
无参数退出码 2，未打开测试窗口。

## 已通过

- 主屏与副屏分别显示绿色、蓝色测试画面，实际解码状态为 D3D11 硬件解码。
- 主屏中心单击仅一次按下、一次抬起，全局坐标 (960,540)。
- 副屏中心单击仅一次按下、一次抬起，全局坐标 (2880,540)，另一屏计数不变。
- 主→副→主→副切换，generation 依次 1、2、3、4；切换后默认只查看。
- 副屏按住 Ctrl 后切回主屏，未发送测试 key-up，远端观察到 Ctrl 已释放。
- 再次在副屏按住 Ctrl，限时副屏自动移除；viewer 经 reconnecting 自动恢复
  到仅有主屏的新 session，画面和输入通道 ready，默认只查看，Ctrl/鼠标均释放。
- 完整辅助日志含 55 条拓扑记录、600 条输入记录；最终仅剩原主屏。
- 关闭本机隔离 viewer 和 Desktop 后恢复 90 原服务：Running、恢复标记存在、
  暂存进程 0、输入释放标志 0；所有本轮计划任务停止后删除，远端暂存目录清理。
  本机安装版未更新，私有测试数据保留。

## 证据与范围

首次测试通过命令任务缓存读取旧的开头计数，无法用来判断点击结果，整轮输入
断言不采信。第二轮改用独立输出文件，每次读计数检查更新时间不超过两秒。
收尾首次 Base64 输出读取受分块长度限制，随后用专用二进制下载重新取得四份
完整日志，逐一核对远端 SHA-256 并解析全部 JSON 行。

恢复截图有其他窗口遮挡，未归档截图；颜色比较仅使用未遮挡位置，结合实际
viewer 状态与远端输入日志判断，不宣称全画面像素验收。窗口关闭使用原生
WM_CLOSE；CDP 的 Tauri close 调用被能力限制拒绝，未改产品权限绕过。

本轮未测实际帧率，不将配置 15 FPS 视为性能通过。混合 DPI、旋转、负原点、
跨平台多屏、长期稳定性仍待完成，因此完整交付条目仍为 10/53，不能作为代码
完成比例。结构化状态、坐标、日志及二进制哈希见
[验收数据](remote-desktop-windows-dual-viewer-2026-10-18.json)。
