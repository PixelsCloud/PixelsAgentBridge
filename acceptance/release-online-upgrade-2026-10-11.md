## 已通过

- Windows x86_64：官网当前安装包为 1.2.81。本地安装包的长度与 SHA-256 和公开发布元数据一致；测试机从 1.2.75 覆盖安装至 1.2.81，静默安装退出码为 0。安装后 Executor 服务运行、Desktop 辅助进程重新启动、远程连接恢复，安装目录没有残留回滚文件。
- Windows 安装器回归脚本 `packaging/desktop/windows/test-install-files.ps1` 通过：正在运行的 MCP 被替换并重新拉起；发布阶段失败会恢复旧二进制；延迟退出的进程不会让已经完成的替换被错误回滚。
- Windows 实机故障注入：在停止服务后、复制新文件前注入安装错误。安装器返回失败，恢复旧文件并重启 Executor 与会话监督任务；测试机保持在 1.2.81，可再次通过 MCP 连接。故障注入脚本和安装包已从测试机清理。
- macOS aarch64：Desktop 的“关于”页发现 1.2.71，从官网下载并进入“安装更新”；用户在 Mac 本机完成系统安装授权后，应用自动重新打开，标题显示 1.2.71。账号登录、设备身份、已保存设备、Executor 连接及屏幕录制/辅助功能权限保留。升级后“关于”页显示已安装包 1.2.71、没有待安装更新。
- 公开更新接口对已安装的 Windows 1.2.81 和 macOS 1.2.71 均返回 204，没有把当前版本误报为新版本。
