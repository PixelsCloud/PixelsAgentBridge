# 远程桌面标题栏与统计浮层

本次为 `feat/remote-desktop-v1` 在 `77dbf60` 之后的界面改动。Windows 已作为 1.3.11 发布到 COS，并验证公开更新接口及完整下载；Mac 1.2.75、Linux Desktop 1.0.4 仍不包含本次界面改动。

## 实现

- 设备菜单的“远程桌面”增加显示器图标。
- 查看器复用主窗口的 42px 自定义标题栏样式、品牌图标与窗口按钮；屏幕选择、FPS、启用操作、Ctrl+Alt+Delete、全屏和协助完成入口均放入标题栏。保留拖动、双击最大化和窄窗口适配。
- 连接、查看/操作模式、分辨率、解码方式及采集上限移入右下角半透明统计浮层，点击收起为 `i`，再点击展开。编码预算按目标值显示，不冒充实测帧率或码率。
- Windows 使用原生透明弹出窗口，macOS 使用 AppKit 按钮，Linux 使用 GTK Overlay 按钮，直接叠加于原生视频表面。统计文本只经过本机 UI 通道；浮层点击不发送远端鼠标事件。已有可靠传输、鉴权和远端消息格式保持原有实现。
- 本机光标读取在统计更新期间保持同一个未完成的读取，避免取消半包读取；光标来源结束后本机统计仍可更新。

## 保留的失败与边界

第一版 Windows 透明子窗口在实际媒体进程中创建失败，改用带拥有者的透明弹出窗口后，通过独立探针和实际查看器验证。失败日志保留。

实际查看器核对中，最初用 `WS_CAPTION` 位判断是否有系统标题栏，不适用于 Tauri 保留窗口阴影样式的实现；随后改为核对实际客户区与 42 DIP 视频起点。另一次截图准备把主窗口临时设成 topmost，跨进程浮层未随之升为 topmost；撤销测试驱动人为增加的置顶状态后，普通窗口的命中、截图与收起/展开均通过。产品没有新增置顶功能，也不将置顶场景记为通过。

原始构建、探针、GUI 状态与截图保存在忽略目录 `.build/remote-desktop/viewer-chrome-20261021/`。截图含测试机画面，仅保留本地，不提交到仓库。不重复此前已通过的整套远控矩阵；2/8 小时测试继续暂缓。
