Pixels Agent Bridge - Linux headless (x86_64, glibc 2.36 or newer)

Executor, MCP and offline document worker. No Desktop, display server, logind or graphical login
is required for core tools. Install Git and your workload programs separately.

One-line installation/upgrade (requires a published Linux release):
  curl -fsSL https://agent.rgaa.vip/install.sh | bash
Uses the official service on first install; preserves configured URLs on upgrade.
The bootstrap verifies the release signature, checksum and runtime libraries.

Application configuration is TOML: /etc/pixels-agent-bridge/config.toml
  control_url = "wss://pab.rgaa.vip/control"
  relay_urls = ["https://pab-relay.rgaa.vip"]
  [executor]
  # device_name = "my-linux-server"
  # log_level = "info"
  # data_dir = "/var/lib/pixels-agent-bridge"
Edit: sudo nano /etc/pixels-agent-bridge/config.toml
Apply: sudo systemctl restart pixels-agent-bridge-executor.service
Existing TOML (including comments) is retained on reinstall and uninstall.
Old settings.env is migrated as data, never executed; unsupported shell syntax
stops the upgrade before the running service is changed. Install arguments set
defaults only on a new installation; edit the TOML to change an installed system.

Local package, official service (root; systemd required):
  sudo bash install.sh

Local package, self-hosted service:
  sudo bash install.sh wss://YOUR_SERVER/control https://YOUR_RELAY
  sudo systemctl status pixels-agent-bridge-executor.service

Container / external process supervisor (no systemd):
  sudo bash install.sh --no-service wss://YOUR_SERVER/control https://YOUR_RELAY
  sudo /opt/pixels-agent-bridge/run-executor.sh
Persist /etc/pixels-agent-bridge and /var/lib/pixels-agent-bridge in containers.
Stop your external supervisor before upgrade or uninstall.

Once Executor has registered with your server, display its device code/password:
  sudo /opt/pixels-agent-bridge/run-executor.sh show-access
Do not paste this password into public logs. The installer never prints it.

For an AI client running here, register the stdio command:
  /opt/pixels-agent-bridge/run-mcp.sh
Run MCP as the AI client's user. Its data is stored in that user's directory,
separately from the root Executor database.
Root Executor can run supported tools as an explicitly selected OS user.
GUI application, screenshot and desktop input tools are unavailable here.
Service inventory/control requires systemd; login-session inventory needs logind.

Upgrade: repeat the one-line command, or run install.sh from the new package.
Device identity and task data in /var/lib/pixels-agent-bridge are retained.
Old Linux Desktop binaries/autostart entries are removed during upgrade.
Uninstall:
  sudo /opt/pixels-agent-bridge/uninstall.sh
Program files are removed; device and user data are retained.
